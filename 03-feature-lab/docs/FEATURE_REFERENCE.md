# Guttation Feature Lab：数值特征完整计算参考

本文档对应当前 `src/features_v2/`、`src/batch_features.py`、`src/folder_loader.py` 的实现。理论名称与代码实际行为有差异之处，会在“实现核对说明”中单独指出。

## 1. 一行数据代表什么

每一行代表一个递归扫描到的子块图片。全部五组启用、图片可正常读取、并且至少一个母图分组满足空间特征计算条件时，典型输出为：

```text
6 个元数据列 + 5 几何 + 19 纹理 + 26 色彩 + 63 植被指数 + 4 空间
= 123 列，其中 117 列为特征
```

以下情况会改变实际列或单元格：

- 取消某个特征组：该组列不生成；
- 某张图片无法解码：该行仍保留元数据，但特征为空；
- 某母图有效子块少于 4 个或缺少标准行列号：该母图的空间特征为空；
- 如果整个数据集中没有任何母图成功计算空间特征，CSV 的字段并集可能不包含那 4 列，而不是强制补出空列。

CSV 字段顺序以 6 个元数据列开头，其后按行字典中首次出现的特征顺序写出。GUI 表格最多显示 5000 行，CSV 导出始终使用内存中的全部行。

## 2. 元数据列（6 列）

| 列名 | 类型 | 来源与含义 |
|---|---|---|
| `image_path` | 字符串 | 扫描得到的子块图片路径；当前为字符串形式的路径。 |
| `original_image` | 字符串 | 标准文件名中 `_r..._c...` 之前的母图 stem；不匹配时使用整个文件 stem。 |
| `row` | 整数或空 | 文件名 `_r<数字>` 解析出的行号，从 0 开始。 |
| `col` | 整数或空 | 文件名 `_c<数字>` 解析出的列号，从 0 开始。 |
| `grid_strategy` | 字符串或空 | 从父/祖父目录 `grid_<列>x<行>` 得到 `<列>x<行>`，例如 `36x18`。 |
| `label` | 字符串 | 仅当直接父目录名为 `0` 或 `1` 时取该值；否则为空。 |

标准结构：

```text
<root>/grid_36x18/0/tray01_r000_c000.jpg
<root>/grid_36x18/1/tray01_r000_c001.jpg
```

扫描支持 `.jpg`、`.jpeg`、`.png`、`.bmp`、`.tif`、`.tiff`，递归遍历所有子目录。

## 3. 公共冠层掩膜

几何、色彩 YR 和空间覆盖率都使用 `canopy_mask()`：

```text
B、G、R = OpenCV BGR 图像的三个 float32 通道
ExG = 2G − R − B
ExG_norm = 将当前子块 ExG 最小/最大值线性归一化到 0～255
M = 对 ExG_norm 使用 OTSU 阈值，输出 0/255
```

- 每个子块独立归一化、独立求 OTSU 阈值；
- 255 被视为冠层，0 被视为背景；
- 没有额外形态学清理；
- 这是图像分割结果，不等于人工测量的植物学冠层真值。

## 4. 几何特征（5 列）

| 列名 | 计算 | 单位 / 注意 |
|---|---|---|
| `CC` | `N_canopy / N_total` | 0～1 的冠层像素覆盖率。 |
| `GPA` | `N_canopy` | 冠层像素的绝对数量，单位是 px，不是 mm² 或 cm²。不同子块尺寸下不可直接当作相同物理面积。 |
| `IGR` | `1 − CC` | 图像背景比例，不等同于人工空格率。 |
| `LGA` | 背景 8 连通域的最大面积 | 单位 px；包含与边缘相连的大背景区域。 |
| `GPN` | 面积 ≥ `max(4, 0.0005×子块总面积)` 的背景 8 连通域数量 | 小连通域被忽略。 |

## 5. 纹理特征（19 列）

### 5.1 GLCM（14 列）

灰度图先量化到 32 级：

```text
gray_q = uint8((gray / 255) × 31)
distances = [1, 2]
angles = [0°, 45°, 90°, 135°]
levels = 32, symmetric = True, normed = True
```

对 6 个 scikit-image 属性和手工熵分别计算 2 距离 × 4 方向结果的均值与标准差：

| 特征前缀 | 生成列 | 含义 |
|---|---|---|
| `glcm_contrast_` | `_mean`、`_std` | 灰度差平方加权的对比度。 |
| `glcm_dissimilarity_` | `_mean`、`_std` | 灰度差绝对值加权的相异性。 |
| `glcm_homogeneity_` | `_mean`、`_std` | 元素靠近 GLCM 对角线的程度。 |
| `glcm_energy_` | `_mean`、`_std` | 能量，scikit-image 中通常为 ASM 的平方根。 |
| `glcm_correlation_` | `_mean`、`_std` | 灰度线性相关性。 |
| `glcm_ASM_` | `_mean`、`_std` | 角二阶矩。 |
| `glcm_entropy_` | `_mean`、`_std` | 按每个距离/方向的归一化 GLCM 手工计算 `−Σp log2(p)`。 |

合计 `7 × 2 = 14` 列。

### 5.2 LBP（3 列）

使用 `local_binary_pattern(gray, P=8, R=1, method="uniform")`：

| 列名 | 计算 |
|---|---|
| `lbp_entropy` | 对动态数量 bin 的密度直方图计算 `−Σp log2(p)`。 |
| `lbp_mean` | LBP 编码图的均值。 |
| `lbp_std` | LBP 编码图的标准差。 |

### 5.3 Gabor（2 列）

滤波器组：4 个方向 × 2 个频率，9×9 核，`sigma=2.0`、`gamma=0.5`、`psi=0`，频率对应 `lambd=1/freq`。

每个滤波器取 `mean(abs(filter2D(gray, kernel)))`，然后：

- `gabor_mean`：8 个响应均值的平均；
- `gabor_std`：8 个响应均值的标准差。

## 6. 色彩特征（26 列）

### 6.1 四个色彩空间（24 列）

每个空间 3 个通道，每通道输出 `_mean` 和 `_std`，合计 `4×3×2=24`。

| 前缀 | OpenCV 转换 | `c1` | `c2` | `c3` |
|---|---|---|---|---|
| `rgb_` | 直接使用输入 BGR 数组 | **B** | **G** | **R** |
| `hsv_` | `COLOR_BGR2HSV` | H（通常 0～180） | S | V |
| `lab_` | `COLOR_BGR2LAB` | L | a | b |
| `ycbcr_` | `COLOR_BGR2YCrCb` | Y | Cr | Cb |

例如 `rgb_c1_mean` 实际表示蓝色通道均值，不是红色。列名中的 `rgb` 是色彩空间组名，通道顺序仍以 OpenCV 输入为准。

### 6.2 派生指标（2 列）

| 列名 | 计算 |
|---|---|
| `GCV` | `std(G) / (mean(G) + 1e-8)`，绿色通道变异系数。 |
| `YR` | 冠层内黄色像素数 / 冠层像素数。黄色条件：`15≤H≤35`、`S>40` 且 `M>0`；无冠层像素时返回 0。 |

## 7. RGB 植被指数（63 列）

共 21 个指数，每个指数输出：

- `veg_<指数名>_mean`：所有有限像素响应的均值；
- `veg_<指数名>_std`：标准差；
- `veg_<指数名>_range`：最大值 − 最小值。

计算前剔除 NaN 和 Inf。记原始通道为 R/G/B，归一化通道为：

```text
s = R + G + B + ε
r = R/s，g = G/s，b = B/s，ε = 1e-8
```

| 指数 | 当前代码公式 |
|---|---|
| `ExG` | `2G − R − B` |
| `TGI` | `−0.5 × [190(R−G) − 120(R−B)]` |
| `GBDI` | `G − B` |
| `MExG` | `1.262G − 0.884R − 0.311B` |
| `ExR` | `1.4R − G` |
| `ExGR` | `ExG − ExR` |
| `VEG` | `G / ((abs(R)+ε)^0.667 × (abs(B)+ε)^0.333)` |
| `VDVI` | `(2G − R − B) / (2G + R + B + ε)` |
| `CIVE` | `0.441r − 0.811g + 0.385b + 18.787` |
| `NGRDI` | `(G − R) / (G + R + ε)` |
| `RGRI` | `R / (G + ε)` |
| `VARI` | `(G − R) / (G + R − B + ε)` |
| `MGRVI` | `(G² − R²) / (G² + R² + ε)` |
| `EGRBDI` | `(4G² − BR) / (4G² + BR + ε)` |
| `RGBRI` | `(G + R) / (B + ε)` |
| `E-NGBDI` | `1.5 × (G − B) / (G + B + 0.5)` |
| `ExB` | `1.4B − G` |
| `IKAW` | `(R − B) / (R + B + ε)` |
| `COM1` | `0.25ExG + 0.30ExGR + 0.33CIVE + 0.12VEG` |
| `COM2` | `0.36ExG + 0.47CIVE + 0.17VEG` |
| `GBRI` | `G / (B + ε)` |

这些指数基于 8-bit 通道值计算，未做辐射定标、光照归一化或冠层掩膜限制。

## 8. 空间分布特征（4 列，母图级）

空间组独立于几何组：只要勾选 `spatial`，即使未勾选 `geometry`，程序也会另行计算每个可读取子块的 CC。

### 8.1 母图覆盖率矩阵

按 `(original_image, grid_strategy)` 分组：

1. 要求组内至少 4 个图片，并且所有条目都有标准 `row/col`；
2. 矩阵大小为 `(max(row)+1) × (max(col)+1)`；
3. 每个子块的 CC 放回对应 `(row,col)`；
4. 缺失或无法读取的子块保持 NaN；
5. 计算结果回填到同一组的所有行，因此同一母图、同一策略的 4 个值相同。

如果不同目录中存在相同 `original_image + grid_strategy`，它们会被视为同一组；准备数据时应保证母图命名唯一。

### 8.2 四项指标

| 列名 | 当前实现 |
|---|---|
| `GCCV` | 有效 CC 的总体标准差 ÷ 平均值；平均值接近 0 时返回 0。 |
| `MI` | 有效格上的 Moran’s I，使用 8 邻域权重；方差接近 0、有效格不足或权重为 0 时返回 0。 |
| `CE` | 将有效 CC 除以本组最大值，再在 `[0,1]` 上生成 10 bin 直方图并计算熵形式；最大值 ≤ 0 时返回 0。 |
| `LAC` | `(std(CC)/mean(CC))² + 1`；平均值接近 0 时返回 1。这是简化指标，不是完整的多尺度盒计数 lacunarity。 |

### 8.3 实现核对说明：CE 与 MI 边界

这两个细节对科研复现非常重要：

1. **CE 当前不是严格的概率直方图熵。** 代码调用 `np.histogram(..., density=True)` 后直接对非零 bin 的密度值执行 `−Σh log2(h)`，没有再把密度值归一化为总和 1 的概率 `p_k`。因此它可能与理论上的 coverage entropy 不同，甚至不保证非负。跨数据集比较或写论文公式前，应确认是否需要改为概率直方图实现。
2. **MI 使用 `np.roll` 取得 8 邻域。** 这会使矩阵对侧边界形成循环邻接，而不是简单在边缘截断邻居。若实验设计要求普通非循环皇后邻接，应先调整边界实现再复现实验。

本文档保留并明确指出当前行为，没有把理论定义冒充为代码已经完成的行为。

## 9. `features_meta.json` 的真实内容

GUI 和批处理通过 `write_features_meta()` 写出：

- `meta_columns`：6 个元数据字段的中文解释；
- `groups`：5 个特征组的组级说明；
- `enabled_groups`：本次启用的组名列表。

**当前 JSON 不是 117 个字段逐列展开的数据字典。** 逐列公式以本文档为准；如果需要逐列机器可读元数据，可在 `write_features_meta()` 上扩展，而不会影响数值计算。

## 10. 数值结果使用建议

- 统一图片位深、色彩处理、网格策略和标签口径后再比较特征；
- `GPA/LGA` 是像素量，跨不同子块尺寸或分辨率时应归一化或分层分析；
- 空间特征在同一母图的各行重复，不宜把每个子块行当成都提供了独立空间观测；
- 下游模型若按行随机切分，同一母图的子块可能同时进入训练集和测试集，产生泄漏；科研上通常应按 `original_image` 分组切分；
- 对 CE、MI 和任何修改过的算法，先固定实现版本，再重新生成全部实验特征，避免混用新旧口径。

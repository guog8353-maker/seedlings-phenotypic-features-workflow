# Guttation Label Studio

## 水稻吐水精准标注与数据集导出平台

Guttation Label Studio 用于把秧盘全景图或其他高分辨率图片整理成可训练的子块数据集。当前主工作流以**像素级笔刷掩膜**为核心，而不是旧版说明中的“鼠标逐格点击赋标签”。

完整流程：

```text
选择图片工作区 → 四点透视校正（可跳过）→ 笔刷绘制吐水掩膜
→ 设置/切换网格 → 按掩膜面积派生 0/1 标签
→ 暂存工作状态 → 单网格或多网格导出
```

软件始终在原图或校正图坐标系中计算掩膜、网格和导出子块；界面缩略图只负责显示，不会把标注降采样后再导出。

---

## 1. 主要功能

- 扫描工作文件夹中的 JPG、JPEG、PNG、BMP、TIF、TIFF 图片并逐张处理。
- 原图与最长边 1600 像素的显示预览分离，支持 Unicode/中文路径。
- 任意顺序点选秧盘四角，自动排序并透视校正为矩形；也可直接使用原图。
- 用连续笔刷绘制 0/255 掩膜，支持橡皮、笔画撤销、清空和三种掩膜视图。
- 以多特征传统图像算法自动预标注确认候选，再由人工修正。
- 自定义列×行网格，提供 36×18、41×20、48×28 三个默认预设。
- 根据每个网格内的掩膜面积比例自动派生 `0/1` 标签。
- 暂存掩膜、校正矩阵、网格和笔刷参数，支持跨图片、跨会话继续工作。
- 当前图片单网格导出、当前图片多网格导出、全部暂存图片批量多网格导出。
- 输出带母图名和零起始行列号的子块图片，以及 CSV 和掩膜面积列。
- 集中记录 `logs/app.log`、`logs/errors.log`，错误弹窗可复制完整 traceback。

## 2. 安装与启动

建议 Windows 10/11 + Python 3.12。

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `启动软件.cmd`。脚本优先使用本目录 `.venv`，否则查找系统 `PATH` 中的 `pythonw`。

### 可选配置文件

没有 `config.json` 时，程序使用源码中的默认配置。需要固定个人偏好时：

1. 复制 `config.example.json`；
2. 把副本命名为 `config.json`；
3. 修改后重新启动。

`config.json` 是本地个人配置，已被总仓库 `.gitignore` 排除；`config.example.json` 才是应上传的模板。

## 3. 推荐的完整标注流程

1. **选择工作文件夹**：放入待标注母图，建议每张图片使用唯一且不重复的 stem。
2. **选择秧盘区域**：点四个角，确认识别区域；不需要校准则点击“跳过校正”。
3. **确认校正**：软件生成校正图，并自动保存到工作区 `rectified/`。
4. **应用分块**：先建立网格，便于使用自动预标注和观察派生标签。
5. **笔刷标注**：只涂真实吐水水珠区域；必要时用橡皮和纯掩膜视图修正。
6. **检查吐水格**：状态栏显示掩膜像素数和达到阈值的格子数。
7. **暂存并下一张**：完成所有图片；普通上一张/下一张和关闭软件也会自动暂存。
8. **导出**：只用一种网格时选“导出当前数据集”；需要多策略时配置多分块并批量导出全部暂存。
9. **人工复核**：检查 `0/1` 目录、CSV 和若干子块，确认标签口径后再交给软件三或训练流程。

> 必须先校正、后绘制掩膜。校正会改变工作坐标系；不要在校正后继续沿用校正前坐标下绘制的掩膜。

## 5. 秧盘区域校正：每个选项

| 组件 | 工作方式 |
|---|---|
| 选择秧盘区域（点4个角点） | 可切换按钮。开启后左键在图上加点，最多 4 个；点选模式优先于笔刷和平移。 |
| 左键选点 | 坐标会换算回原图并钳制在图片范围内，界面显示序号和四边形预览。 |
| 选点模式右键 | 撤销最后一个角点。 |
| 撤销点 | 与选点模式右键相同，删除最后一个点。 |
| 重选 | 清空全部角点，便于重新点选。 |
| 校正尺寸：宽 / 高 | 两个输入框都留空时自动计算；两个都填写时才使用手动尺寸。只填写一个不会形成有效手动尺寸，仍会采用自动尺寸。 |
| 确认校正 | 排序四角、检查退化、计算 H 矩阵并 warp；随后网格、掩膜和导出都基于校正图。 |
| 跳过校正 | 清除当前校正参数，状态显示使用原图。后续暂存的 `rectified` 为 false。 |
| 校正状态 | 显示未校正、已跳过或已校正尺寸；成功时还会标明已保存。 |

### 5.1 角点排序与失败条件

`rectify.py` 先按相对质心的极角排序，再以 `x+y` 最小者作为左上点，并统一为顺时针 `[左上, 右上, 右下, 左下]`。一般无需按固定顺序点击，但秧盘若旋转很大，应检查排序预览和校正结果。

以下情况会拒绝校正并显示原因：

- 角点明显超出图像范围；
- 四边形面积小于整图面积的 0.1%；
- 四边形自交或退化。

### 5.2 输出尺寸和边界

- 自动宽 = 上下两边长度的平均值，自动高 = 左右两边长度的平均值；
- 宽高均四舍五入为整数，并限制在 1～4096；
- 手动宽高同样被限制在 1～4096；
- 使用 `cv2.getPerspectiveTransform` 和线性插值；
- 边界使用 `BORDER_REPLICATE`，即复制边缘像素而不是填黑。

校正图自动写为：

```text
<工作区>/rectified/<母图名>_rect.png
```

原图到校正图的 H 矩阵和四角坐标会在暂存时写入 `annotations/<母图名>_state.json`。使用“导出当前数据集”且当前存在校正信息时，还会额外写出 `rectify_info.json`。

## 6. 笔刷、掩膜和鼠标操作

### 6.1 每个笔刷组件

| 组件 | 工作方式 |
|---|---|
| 笔刷半径数字框 | 范围 2～400，单位是**当前工作原图像素**，不是屏幕像素。与下方滑条双向同步，并写入本地配置。 |
| 笔刷半径滑条 | 与数字框控制同一半径；大范围图片可调大，微小水珠建议调小。 |
| 画笔模式 / 橡皮模式 | 可切换按钮。画笔模式下左键写 255；橡皮模式下左键写 0。按钮文字表示当前模式。 |
| 撤销笔画 | 删除最近一次完整笔画并重放此前笔画；最多保留最近 20 笔。一次按下到松开算一笔。 |
| 清空掩膜 | 把当前工作图大小的掩膜全部置 0，并清空笔画历史；没有额外确认对话框。 |
| 掩膜视图：半透明叠加 | 在底图上叠加半透明红色掩膜，便于判断水珠位置。 |
| 掩膜视图：纯掩膜（黑白） | 用黑白掩膜替代底图显示，白色为吐水区域，黑色为背景。 |
| 掩膜视图：隐藏 | 显示底图，不绘制掩膜；掩膜数据本身不会被删除。 |
| 只显示底图 | 隐藏掩膜和格子标签色块，但不删除数据。网格线、角点和悬停提示仍由各自开关/状态控制。 |
| 自动预标注（多特征检测） | 按当前网格逐格检测，把 confirmed 候选以圆形写入现有掩膜；不会先清空人工掩膜。疑似和排除候选不写入。 |

从暂存状态恢复掩膜、调用 `set_mask()` 或自动预标注后，旧笔画历史会清空，因此“撤销笔画”主要适用于当前连续编辑会话，不等于完整的任意历史撤销系统。

### 6.2 鼠标操作表

| 操作 | 普通标注模式 | 四角点选模式 |
|---|---|---|
| 左键按下并拖动 | 连续绘制或擦除掩膜；快速拖动时在相邻轨迹点之间线性补间，避免断线。 | 单击添加一个角点。 |
| 右键拖动 | 平移图片。 | 单击撤销一个角点。 |
| 中键拖动 | 平移图片。 | 不用于平移。 |
| 滚轮 | 以鼠标位置为中心缩放；向上 ×1.1、向下 ×0.9，最大 20 倍，最小缩放保证图片仍可辨认。 | 相同。 |
| 鼠标移动 | 状态栏显示所在格 `(row, col)` 和当前派生标签；格子显示悬停高亮。 | 用于选择角点位置。 |

平移后至少保留约 60 像素宽的图片区域在视口内，降低图片被拖出视图后“消失”的概率。

### 6.3 掩膜数据细节

- 掩膜类型为 `uint8`，值只有 0 和 255；
- 尺寸始终匹配当前工作图；
- 恢复尺寸不一致的旧掩膜时使用最近邻缩放；
- 显示缓存最长边与预览一致，但缓存不参与导出；
- 掩膜像素统计使用 `np.count_nonzero`；
- 笔刷轨迹重放、网格标签和 CSV 的 `mask_area_px` 都基于原工作图坐标。

## 7. 网格与标签派生：每个选项

| 组件 | 工作方式 |
|---|---|
| 36×18 / 41×20 / 48×28 预设 | 立即设置列、行并应用网格。预设列表来自 `presets` 配置，可修改模板增加或减少。 |
| 列(M) | 1～200，默认 36。表示水平方向子块数。 |
| 行(N) | 1～200，默认 18。表示垂直方向子块数。 |
| 交换 | 交换列数和行数，并立即重新分块。 |
| 应用分块 | 按当前图片尺寸重建全部网格坐标，保存当前列/行配置，并重新从掩膜派生标签。 |
| 显示网格线 | 控制当前画布的网格边界和索引显示；不改变网格数据或导出。初始状态来自配置，当前界面切换只作用于本次运行。 |
| 网格信息 | 显示图片宽高、列×行和用整数除法估算的单元尺寸；实际边界使用四舍五入，边缘单元可能相差 1 像素。 |

### 7.1 网格边界

网格坐标使用半开区间 `[x1, x2) × [y1, y2)`：

```text
x1 = round(col × width / cols)
x2 = round((col + 1) × width / cols)
y1 = round(row × height / rows)
y2 = round((row + 1) × height / rows)
```

最后一列/行强制结束于图片宽/高，因此不会因整除余数遗漏边缘像素。

### 7.2 从掩膜派生 0/1 标签

对每个格子计算：

```text
mask_ratio = 格内非零掩膜像素数 / 格内总像素数
label = 1，当 mask_ratio >= mask_threshold
label = 0，其他情况
```

- 默认 `mask_threshold = 0.01`，即 1%；
- 阈值可在 `config.json` 中修改，界面没有单独数字框；
- 修改网格后，同一掩膜会重新计算所有格子标签；
- 界面只给 `1` 格添加半透明红色，`0` 格保持无底色的照片显示，避免整图被绿色覆盖；
- 如果从未创建掩膜，当前单网格导出会把未显式标注的格子按默认 `0` 导出。

**这不是水珠计数。** 一个大格中少量白点可能达不到 1%，一个大面积涂抹又可能使多个格成为 1。调整阈值和网格时必须结合子块尺寸复核。

## 8. 自动预标注如何工作

自动预标注使用 `GuttationDetector`，不是神经网络。它逐格读取原始分辨率图片，依次执行：

1. HSV 绿色叶片分割；
2. 用高斯背景估计寻找局部显著高亮、低饱和且靠近叶片的区域；
3. 3×3 开运算清理候选掩膜；
4. 建立大面积低圆度高亮区域的反光掩膜；
5. 提取外部轮廓，计算面积、圆度、中心、内部/环带亮度和颜色；
6. 先执行硬排除，再计算五路加权分数；
7. 达到确认阈值的候选被画成实心圆加入人工掩膜。

### 8.1 硬排除规则

| 规则 | 默认行为 |
|---|---|
| 面积过大 / 过小 | 面积必须位于 `max(4, 格面积×0.00008)` 与 `格面积×0.02` 之间。 |
| 形状不圆 | 圆度 `4πA/P² < 0.45` 时排除。 |
| 叶片反光 | 候选中心落在大面积、低圆度的高亮反光区内时排除。 |
| 局部对比不足 | 候选内核与外扩 9×9 环带的 V 差 < 8 时排除。 |

### 8.2 综合评分

通过硬排除的候选按下式得分：

```text
score = 0.20 × position
      + 0.25 × shape
      + 0.20 × brightness
      + 0.15 × color
      + 0.20 × context
```

- `shape`：圆度从 0.3 到 0.9 映射到 0～1；
- `brightness`：60% 局部对比项 + 40% 内核亮度项；
- `color`：70% 低饱和项 + 30% 非绿叶内部项；
- `position`：根据候选中心在叶片距离变换图上的位置，靠近叶缘区域得分更高；
- `context`：格内叶片比例 ≥ 2% 时为 1，否则为 0.4。

候选分为：`confirmed ≥ 0.70`、`suspect ≥ 0.45`、其余 rejected。**界面只把 confirmed 加入掩膜，suspect 不会自动标成 1。**

当前按钮不会自动弹出或导出 `guttation_report.json`，也不会自动显示三色调试图；`write_report()` 和 `render_debug()` 是供二次开发调用的检测器接口。

### 8.3 `GuttationConfig` 高级参数

参数位于 `src/guttation_detector.py`，需要修改源码或通过 Python 实例化配置，不在 GUI 中逐项暴露。

| 参数 | 默认 | 含义 |
|---|---:|---|
| `leaf_h_min` / `leaf_h_max` | `35 / 95` | OpenCV HSV 叶片色相范围。 |
| `leaf_s_min` / `leaf_v_min` | `40 / 20` | 叶片最小饱和度和亮度。 |
| `bright_delta` | `25` | V 高于局部高斯背景的候选阈值。 |
| `max_saturation` | `90` | 水珠候选和反光区域的最大饱和度。 |
| `min_area_ratio` / `max_area_ratio` | `0.00008 / 0.02` | 候选面积占格面积的下限/上限。 |
| `reflection_area_ratio` | `0.20` | 大反光连通区至少占格面积的比例。 |
| `reflection_max_circularity` | `0.35` | 大高亮区域低于此圆度才作为反光排除区。 |
| `w_position` | `0.20` | 位置评分权重。 |
| `w_shape` | `0.25` | 形态评分权重。 |
| `w_brightness` | `0.20` | 亮度/对比评分权重。 |
| `w_color` | `0.15` | 颜色评分权重。 |
| `w_context` | `0.20` | 叶片环境评分权重。 |
| `confirm_threshold` | `0.70` | confirmed 阈值；主窗口创建检测器时也显式使用 0.70。 |
| `suspect_threshold` | `0.45` | suspect 阈值。 |
| `edge_near_ratio` | `0.06` | 叶缘近邻距离占格对角线的比例。 |

## 9. 暂存、导出与多分块：每个选项

| 组件 | 工作方式 |
|---|---|
| 暂存并下一张 | 保存当前掩膜、网格、校正和笔刷状态，成功后加载下一张；最后一张会提示全部暂存完成。 |
| 导出当前数据集 | 按当前网格在后台导出当前图片所有格子，使用当前输出目录，不写 `grid_列x行` 子目录。完成后显示 CSV 路径。 |
| 批量导出全部暂存（按多分块） | 读取工作区全部 `*_state.json`，对每张暂存图片依次执行多分块导出；优先读取校正图，缺失时回退状态中的原图路径。 |
| 多分块策略输入框 | 接受 `36x18,41x20,48x28` 等文本；分隔符可用中英文逗号、分号或空白，乘号可用 `x/X/×/*`。 |
| 按多分块导出当前图片 | 只对当前图片依次导出每种策略，并生成这次调用的合并 CSV。此操作在前台循环执行。 |
| 输出目录输入框 | 相对路径按当前工作目录转绝对路径；留空时使用 `output`。 |
| 浏览输出目录 | 选择目录并写入本地配置；下次启动可恢复。 |

批量导出进度对话框的“取消”会在图片/网格步骤之间检查，不会中断正在写出的单个格子。缺失状态图片或校正图且原图路径也不存在时，该状态会被跳过。

### 9.1 当前图片单网格导出结构

```text
<输出目录>/
├── 0/
│   └── <母图名>_r002_c003.jpg
├── 1/
│   └── <母图名>_r000_c001.jpg
├── labels.csv
└── rectify_info.json          # 仅当前有校正信息时生成
```

`labels.csv` 字段：

| 字段 | 含义 |
|---|---|
| `image_path` | 当前实现写出的子块绝对路径。 |
| `label` | `0` 或 `1`。 |
| `row` / `col` | 从 0 开始的行列号。 |
| `original_image` | 不带扩展名的母图 stem。 |
| `mask_area_px` | 该格内非零掩膜像素数；当前主窗口会提供此列。 |

**覆盖行为**：每次单网格导出都会重写输出根目录的 `labels.csv`，但不同母图的子块图片会继续保留。因此该 CSV 主要对应当前这次导出，不应把它误认为自动累积所有历史图片的总表。需要总表时使用多分块合并导出或自行合并记录。

### 9.2 多分块导出结构

```text
<输出目录>/
├── grid_36x18/
│   ├── 0/<母图名>_r000_c000.jpg
│   ├── 1/<母图名>_r001_c002.jpg
│   └── labels.csv
├── grid_41x20/
│   ├── 0/ ...
│   ├── 1/ ...
│   └── labels.csv
├── grid_48x28/
│   └── ...
├── labels_merged.csv
└── rectify_info.json          # 不由多分块按钮自动生成
```

- 每种策略独立计算网格和标签，**不是把已导出的低分辨率子块再次缩放**；
- 所有策略都直接裁剪当前原工作图，掩膜则按新网格重新统计；
- 合并表比单策略表多一个 `grid` 字段，例如 `36x18`；
- `labels_merged.csv` 每次调用都会重写，只累积本次“当前图片多策略”或“全部暂存多策略”的记录；
- 多分块导出不会自动额外写 `rectify_info.json`，完整校正参数仍以暂存状态 JSON 为准；单网格“导出当前数据集”可额外生成该文件。

### 9.3 重复运行

相同母图、相同策略和相同行列会覆盖同名 JPG。不同网格策略不会互相覆盖。CSV 不是追加日志，而是当前函数调用生成的快照；需要长期保留多批结果时，应使用不同输出目录或先备份。

## 10. 工作区暂存文件

```text
<工作区>/
├── 原始图片.jpg / .png / ...
├── rectified/
│   └── <母图名>_rect.png
└── annotations/
    ├── <母图名>_mask.png
    └── <母图名>_state.json
```

`state.json` 包括：

- `source_image`：原始图片路径；
- `grid`：当前 `cols`、`rows`；
- `brush`：半径和该图片使用的 `mask_threshold`；
- `rectified`：是否使用校正图；
- `rectify`：四角点、原图到校正图 H 矩阵和输出尺寸。

掩膜单独存为 PNG，避免把大数组塞进 JSON。加载时如果状态显示已校正，会优先读取 `rectified/<母图名>_rect.png`；文件缺失时回退原图。

**迁移工作区注意**：状态中的 `source_image` 是绝对路径。跨电脑移动后，如果原图不在原绝对路径且也没有可用校正图，批量导出会跳过该状态。迁移后应检查并更新这些路径。

## 11. `config.example.json` 每个字段

| 字段 | 默认 | 工作方式 |
|---|---|---|
| `workspace` | 空字符串 | 启动时若目录存在则自动扫描；留空则不自动加载。 |
| `output_dir` | `output` | 输出目录输入框初始值。 |
| `cols` / `rows` | `36 / 18` | 没有图片级暂存状态时使用的默认网格。 |
| `presets` | 三组数组 | 生成预设按钮，每项顺序为 `[列, 行]`。 |
| `brush_radius` | `25` | 初始笔刷半径，启动时会同时应用到数字框、滑条和画布。 |
| `show_grid` | `true` | 启动时是否显示网格；运行中切换只影响当前画布。 |
| `mask_threshold` | `0.01` | 格内掩膜面积达到该比例即派生标签 1。 |
| `multi_grids_text` | `36x18,41x20,48x28` | 多分块输入框初始文本。 |

程序运行中会更新工作区、输出目录（通过浏览按钮）、当前网格、笔刷半径和多分块文本。图片级网格和阈值优先从各自暂存状态恢复。

## 12. 日志与错误诊断

日志目录固定为软件目录下的 `logs/`：

- `app.log`：调试及以上级别的运行记录；
- `errors.log`：错误及以上级别，包含阶段、异常类型和完整堆栈；
- 控制台：同步输出 `[STAGE]` 和 `[FAILED STAGE]`。

主要阶段名包括 `LOAD_IMAGE`、`VALIDATE_IMAGE`、`RECTIFY_IMAGE`、`DETECT_GUTTATION`、`SAVE_STATE`、`EXPORT`、`MULTI_EXPORT`、`BATCH_EXPORT` 和 `EXPORT_CSV` 等。

错误对话框包含阶段、错误类型、错误信息和日志路径；“复制错误信息”会复制完整 traceback。提交问题时，应同时提供输入图片尺寸、网格、阈值、操作步骤和错误文本，但不要上传需要保密的实验数据。

## 14. 常见问题与使用边界

### 右键没有擦除

当前版本中右键/中键用于平移。擦除请先切换到“橡皮模式”，再用左键涂抹；界面提示已按这一实际行为修正。

### 自动预标注很少或很多

先确认网格尺寸、绿色叶片分割和光照是否适合。该方法是启发式候选筛选，不是训练后的通用模型；任何自动结果都需要人工检查，尤其是水膜、反光、白平衡变化和水珠粘连场景。

### 明明画了水珠，格子仍是 0

检查掩膜面积是否达到格面积的 1%，并切换到“纯掩膜”确认实际涂抹位置。网格越大，单格面积越小；同一掩膜在不同网格下派生标签可能不同。

### 导出图片很大或数量很多

每种 `列×行` 策略生成 `列×行×母图数` 个 JPG。多策略会分别完整导出，不会通过硬链接或复用文件减少空间。请先估算磁盘空间。

### 大图片显示缩小，是否影响精度

不影响导出分辨率。计算和裁剪使用原始工作图，只有 GUI 预览和掩膜显示缓存降采样。但原始大图本身仍需载入内存，超过一亿像素时状态栏只标记 `LARGE_IMAGE_MODE`，并不会自动把全部算法变成分块流式处理。
